What do these findings mean?

Shor findings (RSA, elliptic curves, Diffie-Hellman, DSA) are broken outright by a large quantum computer running Shor's algorithm. No key size helps: the fix is migrating to the NIST post-quantum standards, ML-KEM (FIPS 203) for key exchange and encryption, ML-DSA (FIPS 204) for signatures. Data encrypted today can be recorded and decrypted later ("harvest now, decrypt later").

Grover findings (AES-128, SHA-1, 3DES) are weakened, not broken: Grover's algorithm roughly halves their strength. Larger keys and hashes (AES-256, SHA-256 or better) fix them.

In transition means the classical algorithm sits next to post-quantum code, typically a hybrid scheme such as X25519MLKEM768: the migration is under way. Test code findings are labelled so they can be told from what ships.

When a finding shows a path, the algorithm was written somewhere else and reached the crypto call through variables, parameters or return values; the path goes from where it is written to where it is used.
